# Ganpati Booking Web Application

A web-based application for browsing Ganpati idols, booking available slots, and managing user bookings through a simple interface.

## Features

- User Registration and Login
- Ganpati Idol Catalog
- Booking Management
- Available Slot Booking
- JWT-based Authentication
- Contact and Inquiry Form
- REST API Integration

## Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JSON Web Token (JWT)

## Project Structure

- `backend/` - Server-side logic and APIs
- `backend/controllers/` - Application controllers
- `backend/models/` - Database models
- `backend/routes/` - API routes
- `backend/middleware/` - Authentication and error handling
- `frontend/` - User interface pages
